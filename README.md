## Featured Project

### Automated Neuronal ROI Segmentation in MICrONS Two-Photon Imaging

**Status:** In Progress | Computer Vision (ITAI 1378)

This project explores automated neuronal region-of-interest (ROI) segmentation using public MICrONS two-photon imaging data. The goal is to develop a U-Net-based segmentation application and evaluate predicted neuronal ROI masks against published reference segmentations using IoU and Dice scores.

**Technologies:** Python, PyTorch, U-Net, Computer Vision, Image Segmentation

**[View MICrONS ROI Segmentation Project](https://github.com/NaZhou2024/MICrONS_roi_segmentation)**
